# 📝 Практична робота: Реалізація простого ToDo List (Варіант 8)

## 📌 Загальна інформація
* **Тема:** Реалізація простого ToDo List з використанням DOM-подій та збереження даних у браузері.
* **Мета:** Набути практичних навиків використання подій (Events) та зберігання стану в `localStorage`.
* **Документація по подіям:** [MDN Event Listing](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Events#event_listing)
* **Варіант:** №8
* **Стек технологій:** HTML5, CSS3 (Modern Glassmorphic Dark Design), JavaScript (Vanilla ES6+).

---

## ✅ Виконання всіх 8 завдань лабораторної роботи

| № | Вимога завдання | Статус | Реалізація у коді |
|---|---|:---:|---|
| **0** | Оформлення додатку за допомогою CSS | ✅ | Сучасний Glassmorphism дизайн, адаптивна верстка, анімації, соковита кольорова гама (`style.css`). |
| **1** | Елемент `<input>` для додавання завдання за кнопкою `Enter` | ✅ | Обробник `keydown` на інпуті `#taskInput`, який перевіряє `e.key === 'Enter'`. |
| **2** | Вивід списку із текстом та відформатованою датою/часом | ✅ | Автоматичне формування дати у форматі `DD.MM.YY, HH:MM` (наприклад: `12.12.22, 16:09`). |
| **3** | Чекбокс біля кожного завдання | ✅ | Кастомний елемент `<input type="checkbox">` додається ліворуч від кожного активного завдання. |
| **4** | Виконане завдання перекреслюється, сіріє, чекбокс зникає | ✅ | При кліку на чекбокс додається клас `.completed` (`text-decoration: line-through`, `color: #64748b`, `display: none` для чекбокса). |
| **5** | Хрестик для видалення завдання праворуч | ✅ | Кнопка з іконкою хрестика `<button class="delete-btn">` обробляє подію `click` та видаляє елемент. |
| **6** | Редагування подвійним кліком (`dblclick`) через `<input>` | ✅ | Обробник `dblclick` на тексті міняє `<span>` на `<input class="edit-input">`, підтвердження зміни за клавішею `Enter` або втратою фокусу (`blur`). |
| **7** | Збереження стану додатку в браузері (`localStorage`) | ✅ | Всі операції (додавання, редагування, зміна стану, видалення) синхронізуються з `localStorage.setItem()`. |
| **8** | Сортування та фільтрація "виконаних" та "невиконаних" | ✅ | Панель фільтрів (**Всі**, **Невиконані**, **Виконані**) та випадаючий список сортування (за статусом, нові, старі). |
